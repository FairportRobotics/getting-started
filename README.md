# Getting Started - Python
Welcome to Fairport Robotics software team!  Here are the steps to take to get started.

## First Steps

1. [Download and install](https://www.python.org/downloads/) Python if it is not installed. How can I tell if Python is installed? Open a command prompt and type `python --version` for Windows or `python3 --version` for Linux/Mac.  If it returns a version number, you have python installed.  If it returns an error, you need to install python
2. [Download and install](https://code.visualstudio.com/) VS Code.  There is [full setup instructions](https://code.visualstudio.com/docs/setup/setup-overview). Alternatively you could [download and install](jetbrains.com/pycharm/download/) PyCharm.

## Getting Started

A good practice is to use virtual environments when working with python.  A virtual environment creates a silo to install packages into.  [This video](https://youtu.be/GZbeL5AcTgw) explains the process in VS Code.
